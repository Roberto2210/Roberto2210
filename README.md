#### ⭐ Proyecto destacado

**[Poza Rica No Te Rajes](https://github.com/Roberto2210/poza-rica-no-te-rajes)** — mapa ciudadano en tiempo real que hice durante la inundación de Poza Rica (octubre 2025) para reportar calles cerradas, zonas inundadas y centros de acopio, con validación por votación comunitaria. Lo usaron vecinos, brigadas y autoridades locales, y salió en [Milenio](https://www.milenio.com/virales/crean-app-reportar-calles-inundadas-veracruz-real), [La Silla Rota](https://lasillarota.com/veracruz/estado/2025/10/21/joven-de-poza-rica-crea-pagina-web-para-monitorear-calles-avenidas-afectadas-por-inundacion-563708.html) y [TV Azteca Veracruz](https://www.aztecaveracruz.com/noticias/como-se-llama-la-app-para-reportar-calles-inundadas-en-poza-rica/).
